# Model selection and fallback review

The game selects these model families at process startup. With the imported GLB available, the default is the authored model. Launch Godot with a user argument after `--` to exercise a classic path, for example `godot --path . -- --classic-ferry`. A missing required GLB selects that same path unless a more specific rule appears below. Start a fresh process for comparisons so the static flags, material state and mesh caches reflect the selected mode. [Model builders](../scripts/world/models.gd) · [Ferry classes](../scripts/sim/ferry_class.gd)

| Switch | Selection and live consumers | Existing verification or capture |
| --- | --- | --- |
| `--classic-ferry` | FerryClass tests the Guemes, Hiyu, Evergreen State, Issaquah and Jumbo Mk II imports independently for sizes 1–5. Classic forces all five code-built hulls. The class also supplies deck geometry and vehicle clearance. FerryView fits hull and shadow geometry to that class. | `ferry_view_test.gd`, `ferry_waterline_test.gd`, `art_free_region_test.gd`, `ferry_shots.gd` |
| `--classic-net` | FerryView fits a car-deck net to each end of the hull. FerryNetModel builds the authored rope bays or the classic box net to fit the class. Models caches by class and mode. This switch is independent of hull selection. | `ferry_net_model_test.gd` checks all five sizes in both modes; `ferry_view_test.gd`, `net_shots.gd` |
| `--classic-slip` | WorldBuilder selects transfer spans and trestles; WorldSession supplies ramp and guide availability to Simulation. The span needs the slip GLB. The trestle also needs its own GLB. Guides require all three guide GLBs and can be present independently of the span. Classic uses the code-built dock geometry and omits the moving ramp and fitted guides. | `trestle_profile_test.gd`, `slip_purchase_test.gd`, `slip_shots.gd` |
| `--classic-cars` | VehicleFactory selects authored, weighted cars, trucks and tractor/trailer combinations, or a code-built car or truck with an empty model ID. The latter takes the flat fare path. Mesh scale, dimensions and RNG consumption also depend on this choice. | `vehicle_spawn_test.gd` explicitly selects both modes; `fare_deck_test.gd`, `trailer_paint_test.gd`, `vehicle_sheet.gd` |
| `--classic-trees` | WorldBuilder and Backdrop get pine and broadleaf variant lists from Models. Classic supplies one procedural pine or round tree without the authored distance levels. See the tree switches below. | `forest_proximity_test.gd` covers placement; `tree_shots.gd` and `lod_shots.gd` expose appearance |
| `--classic-gull` | SeagullModel selects the mesh and supplies the matching baked-fold shader material to Seagulls and the capture tool. Models caches each variant separately. The authored mesh carries the folded wing in UV channels. | `model_parts_test.gd` checks the authored part. `seagull_model_test.gd` runs in both modes; `gull_shots.gd` captures the poses |
| `--classic-orca` | OrcaModel selects the body and whether UVs supply individual markings. Cetaceans creates the matching material for the live pod and capture tool. Models caches the two meshes separately. | `orca_model_test.gd` runs in both modes; `orca_lineup.gd` and `wildlife_shots.gd` show the animals |
| `--classic-whales` | WhaleModel selects the humpback and gray whale meshes. Models keeps a cache key for each species and variant. Cetaceans supplies the live material. | `whale_model_test.gd` runs in both modes. `wildlife_shots.gd` captures surfacing whales |
| `--classic-seals` | PinnipedModel selects authored or classic harbor seals and sea lions. Models caches each species and variant. Pinnipeds animates the mesh with species-specific head and hip pivots. | `pinniped_model_test.gd` runs both variants; `haul_out_audit.gd` and `wildlife_shots.gd` show the animals |
| `--classic-sailboat` | VesselAppearance supplies the hull and lights; SailboatView fits the boom, main and jib. The model branch also changes the jib hinge coordinates and sail camber. | `sailboat_rig_test.gd`, `vessel_shots.gd` |
| `--classic-cargo` | VesselAppearance fits container hulls (including the scaled feeder), tankers and bulkers, plus lights and hull lettering. The tanker and bulker GLBs are optional independently once the cargo GLB is available. Classic selects the code-built family. | `vessel_hull_view_test.gd` covers a named feeder; `vessel_shots.gd` |
| `--classic-trawler` | VesselAppearance and FishingBoatView use the chosen hull, livery, fishing gear and lamp positions. | `trawler_gear_test.gd`, `fishing_shots.gd` |
| `--classic-pilot` | VesselAppearance selects the pilot boat, livery and lights. PilotLadder uses the matching launch details. | `vessel_night_lights_test.gd`, `vessel_shots.gd` |
| `--classic-tug` | VesselAppearance selects the tug hull, livery, mast and lights. | `vessel_night_lights_test.gd`, `vessel_shots.gd` |

**Tree comparison options.** Within the authored tree family, `--old-pines` selects the spruce variants. Otherwise the low-poly pine takes precedence when available; `--meshy-pines` selects Jon’s pine set when present, falling back to spruce. `--sprite-trees` uses cards where available, `--cone-trees` selects distant stand-ins for broadleaf and Meshy pine variants, and `--raw-stand-ins` skips their fit correction. `--impostor=`, `--mpine=`, `--broad-card=`, `--lod-fade=` and `--card-tone=` tune transitions or shading for comparisons. The eagle has a separate missing-asset behavior: no eagle mesh is created when its GLB is unavailable. [Trees and wildlife meshes](../scripts/world/models.gd)

**Art decision.** Keep all listed modes pending a family-specific decision. The trailer comparison on TID-317 established identical renders across paints for a mesh-cache change. That evidence covers trailer reuse; it does not establish acceptance of removing classic cars or any other fallback. For each proposed retirement, Jon or the family’s art owner should identify the accepted variants and reference render, say whether the comparison flag is still used, and agree with Paul on missing-import behavior. Record the decision and check both modes before changing the default or removing code. Automated checks above cover specific contracts; capture scripts provide views for review.
