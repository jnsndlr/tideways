# Editable art sources

Keep the current `.blend` files and their Python authoring and export scripts here. Godot skips this directory through `.gdignore`. Look under `assets/models/` for the exported game models. Blender's numbered previous saves, such as `cargo_mid.blend1`, can stay in an artist's working copy. Git history retains earlier committed sources.

## Water studies

The game uses `shaders/water.gdshader`. Keep the five alternate shaders and their UIDs for art comparison. The fold, gem, reference and sharp studies are listed beside `WorldBuilder.WATER_SHADER`. The poster study is a separate posterized treatment. The game and capture tools currently select the production shader.
